# README test-result commentary

Test-result reporting belongs in **cogno-us/cognous-stack-qualification**. Component READMEs describe purpose, setup, interfaces, test commands and limitations, then link here for results. The architecture hub continues to own component selection and release decisions.

## Reporting policy

- Put new run outcomes, pass/fail totals, comparisons and test-result comments in this repository, linked to the relevant run record and component source revision.
- Preserve failures, missing trials, unknown observations, denominators, scope and limitations. Keep deterministic, model, human and operational evidence distinct.
- A historical pass does not qualify a changed source or configuration. Migration is not a rerun, a fresh security review, a release decision or deployment approval.
- Preserve raw observations, manifests, hashes, fixtures, source pins, licenses and original notices. Keep immutable evidence bytes at their original locations and link them here.
