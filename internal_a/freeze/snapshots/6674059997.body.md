### 10. Refusal, failure and status propagation
Native vocabulary is preserved verbatim; C4 adds only **orchestration classes**, never substituted component statuses. Mapping to the existing runner vocabulary (`runner.py`: `OBSERVED = ACCEPTED/REFUSED/ERROR/UNKNOWN`, `STATUSES = PASS/FAIL/BLOCKED`, `invocation_status NOT_INVOKED`, `effect_status NOT_ATTEMPTED`; `real_c1.ADMISSION_MAP` hold→`REFUSED`):
| C4 class | Meaning | Runner analogue |
|---|---|---|
| `ACCEPTED` | the component natively accepted the supplied input for processing (CP `authorized`; Replay/Pack import returned a result) — **not** acceptance of the action | OBSERVED `ACCEPTED` |
| `REFUSED_NATIVE` | the component natively refused: CP `hold`; `ImportContractError` | OBSERVED `REFUSED` (C1 maps hold→REFUSED; C2/C3 use `REFUSED_NATIVE` for import refusals) |
| `FAILED` | adapter, harness, measurement, producer or `ManifestLoadError`-type failure; never a native refusal | OBSERVED `ERROR` |
| `BLOCKED` | a precondition or source identity cannot be established, a gate (AM `proposal_mismatches`) stopped the chain, or no native verdict was observed — an **orchestrator verdict** | STATUS `BLOCKED` / OBSERVED `UNKNOWN` |
| `NOT_EXECUTED` | not invoked (new term) | `invocation_status NOT_INVOKED` |
Rules: (1) each boundary record = {native_outcome verbatim, native result or exception type+message, `orchestration_class`, input/output sha256, `retains_upstream_refusal` (bool), `carried_authorization_state` verbatim (`authorized` — historical, not current permission, per L2 — or `held`)}; (2) the earliest native refusal is recorded and never overwritten; (3) a downstream boundary **keeps its own honest class** (e.g. Replay `ACCEPTED` as `IMPORTED partial B005+B004`, Pack `ACCEPTED valid True`) but must set `retains_upstream_refusal: true` and `carried_authorization_state: held`; its class is never relabelled `REFUSED_NATIVE` and is never read as acceptance of the action; (4) the **chain verdict** is the earliest non-`ACCEPTED` class (`REFUSED_NATIVE@control_plane` for N1-HOLD), with the full vector kept; (5) an upstream `BLOCKED/FAILED/REFUSED` makes later boundaries `NOT_EXECUTED` unless the contract defines a downstream observation of the retained refusal (N1-HOLD only); (6) a missing mandatory input or evidence file fails closed (`BLOCKED`/`FAILED`), never defaults; (7) no refusal, adverse finding or native exception text is erased, rewritten or relabelled; (8) `PASS` for a case means only that observed outputs equal the frozen expectations. **Decision A9.**
