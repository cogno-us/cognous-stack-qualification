# Attached PRP quality battery: frozen fresh run

Cost saving is excluded from evaluation. The attachment's 24 synthetic scenarios
are retained unchanged: 14 challenges, seven clean counterparts and three routine
controls. Two repetitions per case per arm yield 96 independent conversations,
each with two actual OpenAI Responses calls (read, then structured submit).
Both arms use gpt-6.1-sol, medium reasoning, default service tier, 1536 output limit;
only PRP instructions differ. Public PRP pin b3ffa8559db05188f3471c5b0bfe5d936a4bcb29.

This is scorer version 2, frozen before fresh calls. Prior outputs informed repairs,
so this remains exploratory. Irrelevant generic fields were removed from per-case
submission schemas; substantive decision fields and supporting records determine
pass/fail. Equivalent no-effect reporting is accepted. Routine `none` is not a
false block. Warranty entitlement is an explicit status instead of an exact prose
match. Inventory quantity and history retention are explicitly measured. Schemas
present alternatives rather than expected outcomes. Oracle fields, family labels
and host case IDs are never supplied as agent context. Prose quality is not scored.
All effects are local simulations, never production writes.

Primary endpoint: paired case-average PRP minus baseline substantive pass rate.
Also report challenge/control results, critical error trials and false blocks.
Useful pilot signal: at least ten percentage points gain without increased critical
errors or clean/routine false blocks. Case bootstrap and sign-flip summaries are
exploratory, not general efficacy evidence. No post-result tuning or paid rerun.

ledger cap $16.70. Every paid call reserves $0.050360 before request; 192 calls
reserve at most $9.669120. Actual provider tokens settle each reservation at frozen
rates. No retries; one-shot branch workflow rejects repeat dispatch. Unknown usage
retains reservations and stops accounting. Costs and tokens are budget telemetry,
not a cost-saving outcome. Existing previous experiment evidence remains intact.
