### Q4. Is independent live-side isolation reachable under valid authority?

### Q5. Why (proof, premises, failure points)
Proof. Let M be the live host manifest, X_p the persisted decision's manifest, D(.) the extraction `_declared_authority(M, action_id)`.
1. Live ECB leaf = D(M)[1]. `require_authority` reads `workflow_kwargs["manifest"]` once at construction (`registry_governed_lifecycle.py:137-141`, `_declared_authority` 81-90); stored once as `_gl_authority` by `_gl_attach` (`:175`, the only assignment of `_gl_authority` in `src/`; confirmed by grep); leaf emitted via `_gl_common_members` (`:201-202`) -> `ecb.scope_identity` (`effective_configuration_binding.py:130-132`). The base workflow deep-copies the manifest (`bounded.py:1291`).
2. The domain lies inside the manifest, and `manifest_digest = commitment(manifest)` (`bounded.py:86-88`) covers the entire manifest. Every resolve emits `manifest_digest_mismatch` unless `proposal.manifest_digest == commitment(self.manifest)` (`bounded.py:2618-2619`), and the binding copies `proposal.manifest_digest` (`:2584`). `proposal_commitment` covers the proposal, which carries the digest.
3. Hence if leaf_live != leaf_persisted then M != X_p (assuming mint integrity), so by collision resistance H(M) != H(X_p). Either (a) the supplied proposal carries H(M) -> live binding `manifest_digest` and `proposal_commitment` differ from persisted -> base diff non-empty (this is N-CLAIM-JOINT-A10, Q2-A2(ii)); or (b) the proposal carries H(X_p) -> `manifest_digest_mismatch` fires -> base reasons non-empty.
4. In case (b) the ECB is never consulted: `registry_governed_lifecycle.py:267-268` returns `reasons, binding` unchanged when any base reason exists (observed Q2-A2 i/iii, N-CLAIM-JOINT-C1-A04). In case (a) the single comparison `current != persisted.binding` (`bounded.py:1690`; claim `local_authority_effect.py:455`; pin-export `authorization_pin_export.py:181`) is satisfied by the base difference alone, so the leaf is not the sole cause.
5. Therefore a state "base equal, leaf unequal, base reasons empty" does not exist under 1-4. QED.
Premises: P1 leaf is a function of M alone (single constructor read, single `_gl_authority` assignment, all four governed constructors use `require_authority`); P2 `manifest_digest` is a binding member and is forced equal to H(live manifest); P3 `commitment()` is injective on the domain string in practice (collision resistance, canonical encoding); P4 base-reason short-circuit and single-equality structure as cited; P5 persisted leaf was minted from the persisted manifest (no store tampering); P6 manifest is a value-stable mapping.
Where it could fail: (i) P6: a host-authored stateful `Mapping` manifest whose construction-time read differs from its deep-copied value. Execute is protected by `_gl_reverify` -> `manifest_authority_changed` (`:307-309`), but claim and pin-export do not call `_gl_reverify` (`local_authority_effect.py:443`, `authorization_pin_export.py:170`), so on those two legs an adversarial-host construction could in principle equalize the base and move only the leaf. I did not execute or fully trace it (also needs a Registry selection signed for Y); it is outside any supported interface but I cannot rule it out from source alone. (ii) P2/P4 are source-structure facts; a future refactor (e.g. R1, deferred) could break them. (iii) Non-supported instruments (graft; seam patch of `_declared_authority`, never run) do produce the state; they are not valid authority (store write or code patch). (iv) A different reading of "isolation" (only the ECB-comparison inputs held equal) would be satisfiable but is not the record-12 wording. Also: the leaf is informationally redundant with `manifest_digest` in every supported state, so it cannot independently cause any refusal there; its function under valid authority is defence in depth.

### Q6. Does the controlling contract require the impossible construction or the underlying property?
Record 12 item 1 (Class A, controlling) says: "Needs one independent isolation (decision under X, live side rebuilt under Y, all else equal, run execute and pin-export). If not isolable, status is 'not independently demonstrated for this member'." So it names the construction but carries its own fallback: the contract does not compel the impossible construction; it permits the status. Oracle 03 expectation 1 requires that each perturbed member make execute AND pin-export refuse (persisted-side perturbation satisfies the wording; original F3-A recorded that leg PASS on execute and FAIL only on the DEV-PE-1 token/durable-row checks on pin-export). Oracle 03 expectation 8 prescribes a "replayed member copied from another decision or scope (scope member must refuse)" negative control, i.e. the graft is an oracle-sanctioned control type, not an invented one (Q2-A3 on execute is such a control; it was not run for claim or pin-export). Under record 12's own preamble, developer/same-lineage evidence is never independent, so the word "independent" in item 1 cannot be met by any same-lineage artifact regardless of construction. Whether graft/patch evidence counts as the isolation is not decided by the text: CONTRACTUALLY UNRESOLVED (Architect decision, record 13 open item 3).

### Q7. Could independently verified decomposition establish the underlying obligation?
Yes for the safety property (domain change => refusal); no for "the leaf, not manifest_digest, caused it". A decomposition would need, each by an independent party with an independently derived oracle: (L1) dependence lemma: leaf = f(manifest), manifest_digest = g(manifest), g injective on the domain (source audit plus property tests over manifests varying only the domain, incl. multi-action manifests); (L2) closure: no writer of `_gl_authority` other than `_gl_attach`; all four governed workflows use it; (L3) guard order: any base reason suppresses ECB consult; (L4) comparison sensitivity of the leaf PER INTERFACE using the oracle-03-item-8 replay (graft) or a seam patch, run separately for execute, claim and pin-export, with a comparison-side mutant and a live-only mutant (D06-M06 mutates mint and live together, so only a state with equal base distinguishes it); (L5) end-to-end refusal consequences per interface under the scope A/B/C semantics; (L6) controls (untouched, neutral graft). Output would be a conjunction: reachable states either refuse via base guards (L1-L3) or, if the base were hypothetically equalized, via the leaf (L4). That establishes the refusal obligation but explicitly NOT natural isolation, and it relies on P6 and on the non-supported instruments being accepted as evidence class.
