## 5. A25(a) authority_domain determination (Worker A, D)
1. **Invariant:** a change of the live `scope.authority_domain` that is otherwise valid must cause refusal of execute, pin-export and claim, with the leaf demonstrably able to cause it.
2. **Strongest evidence:** D-1 Q2-A2 (execute, natural joint, durable refusal); D-1 Q2-A3 (unsigned-store graft, execute only, one fixture); N-CLAIM-JOINT (claim: base diff `{manifest_digest, proposal_commitment}`, ECB diff `{digest, scope.authority_domain}`, generic `PermissionError`, 0 refusals); persisted-side reseal rows in the original package.
3. **Counterexample that would disprove the property:** a valid live domain change with no refusal, or a refusal path that survives mutation of the leaf comparison (mutant D06-M06 shows joint execute refusal still passes when the graft is mutated, so a joint refusal alone does not show the leaf matters).
4. **Isolation reachable under valid authority?** Not through supported interfaces. 5. **Why:** the live leaf is read once from the host manifest (`registry_governed_lifecycle.py:137-141`, `_declared_authority` 81-90, attached at 175); `manifest_digest` covers the whole manifest and a mismatching proposal digest raises `manifest_digest_mismatch` (`bounded.py:2618-2619`); with any base reason the ECB comparison is skipped (`registry_governed_lifecycle.py:267-268`). Premises: leaf depends on the manifest alone; `manifest_digest` forced equal to the live manifest digest; no digest collision; persisted leaf minted from the persisted manifest; manifest value-stable. Limits: a stateful mapping manifest (`_gl_reverify` is not called in claim or pin-export, untraced), a digest-preimage drift across a code version, and the unsigned-store writer, which Worker E does **not** treat as valid authority.
6. **Does the contract require the impossible construction?** Item 1 requires "one independent isolation ... execute and pin-export" but supplies its own fallback "not independently demonstrated for this member". The contract therefore does not require the impossible construction; it permits the negative status.
7. **Decomposition:** can establish "domain change leads to refusal"; cannot establish that the leaf rather than `manifest_digest` caused it. Needs a dependence lemma, proof nothing else writes `_gl_authority`, the guard-order fact, separate replay/seam cases per interface, comparison-side and live-only mutants, and an independent executor and oracle.
8. **Unqualified:** isolation on every interface; pin-export live side (**NOT DEMONSTRATED**, no case executed, guard-first at `authorization_pin_export.py:145/147` is a source reading); mutants.
9. **Prospective change:** none required; **Option B not applicable** (no frozen definition equates this leaf with another member; item 1 already has a fallback).
**Verdicts:** execute PARTIALLY DEMONSTRATED; claim PARTIALLY DEMONSTRATED (conditional on 06/11, non-journal branch, instrument-attributed); pin-export NOT DEMONSTRATED; isolation STRUCTURALLY UNREACHABLE (supported interfaces, premises above); whether the graft discharges item 1: CONTRACTUALLY UNRESOLVED, with the lead and Worker E reading it as **not** discharging (persisted-side, execute-only, one fixture, not "live side rebuilt under Y").

Fails for an unsigned-store reseal, an unsupported attribute mutation, a cross-version preimage change, or a future regression: nothing asserts the equality at runtime. The freshness-extension route does **not** isolate it: the observed ECB diff is still `{digest, effective_profile_digest}` with the base pair moving.

Existing evidence supplies the first and fourth elements on one workflow and the persisted-side element on a fixture (A19) whose eff equals the host digest, so it cannot separate an eff-slot error from a host-swap error.
8. **Unqualified:** member-specific sensitivity (a joint refusal does not show it: the refusal would occur even if the ECB eff member were ignored, and the classifier reads "mismatch" in C1 where the refusal was approval-only); eff-specific mutants; second workflow family; pin-export leg (source-only).
9. **Prospective:** an Architect ruling adding an explicit fallback or decomposition rule for item 2 (Option B), independent re-verification of cited A19/G1/G2/P5 rows and FXE rows, and the mutant set above or an explicit waiver. No code change.
**Verdicts:** isolation STRUCTURALLY UNREACHABLE (supported interfaces, premises above; proof is lineage-internal); refusal property PARTIALLY DEMONSTRATED; member-specific sensitivity NOT DEMONSTRATED; item 2 for this member CONTRACTUALLY UNRESOLVED and unsatisfied as written.
